# Suncity Spin & Win

A small casino-style web app built in plain HTML, CSS, and JavaScript.

## Features
- Spin wheel with weighted odds
- 70% loss / 30% win probability
- Real-time balance updates
- Bet input validation
- Responsive design for desktop and mobile

## Run it locally
Open `index.html` directly in a browser, or run a quick local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` — main app structure
- `styles.css` — styling and layout
- `script.js` — game logic and wheel animation

## Note
This is a simulated game for demo purposes and not a real money platform.
